## 📊 现状评估

### 当前优势
- ✅ 已完成体积优化（ESM 31KB，gzip 8.68KB）
- ✅ 支持 9 种精美主题，覆盖多种场景
- ✅ 动态加载机制，按需引入依赖
- ✅ 同时支持 tsparticles 和 Three.js
- ✅ 提供 Context API 和 Props 两种使用方式

### 待改进点
- ⚠️ 代码可维护性：核心组件过长，缺少模块化
- ⚠️ 性能策略：缺少设备自适应降级
- ⚠️ 内存管理：缺少 WebGL 上下文清理与实例销毁
- ⚠️ 移动端适配：缺少针对移动设备的专项优化
- ⚠️ 用户体验：主题切换无过渡，缺少加载反馈

- ⚠️ 无障碍：缺少键盘导航、动画偏好支持

#### 1.2 添加错误边界

**问题**：粒子渲染失败会导致整个应用崩溃。

**方案**：

```tsx
// src/components/ParticleErrorBoundary.tsx
export class ParticleErrorBoundary extends React.Component {
  state = { hasError: false };
  
  static getDerivedStateFromError() {
    return { hasError: true };
  }
  
  componentDidCatch(error: Error) {
    console.warn('[react-particle-backgrounds] 渲染失败:', error);
  }
  
  render() {
    if (this.state.hasError) {
      return null; // 静默失败，不影响主应用
    }
    return this.props.children;
  }
}
```

**验收标准**：
- 粒子渲染失败不影响主应用
- 错误信息记录到控制台
- 提供可选的 fallback UI

#### 1.3 优化类型安全

**问题**：`ParticleWave.tsx` 中 Three.js 动态导入使用 `any`。

**方案**：

```typescript
// src/utils/threeLoader.ts
import type * as THREE from 'three';

type ThreeModule = typeof THREE;

export async function loadThree(): Promise<ThreeModule | null> {
  try {
    const req = (globalThis as any).require;
    if (typeof req === 'function') {
      return req('three') as ThreeModule;
    }
    const mod = await import('three');
    return (mod as any).default ?? mod;
  } catch {
    console.warn('[react-particle-backgrounds] Three.js 未安装');
    return null;
  }
}
```

**验收标准**：
- 移除所有 `any` 类型
- 添加运行时类型校验（可选：使用 Zod）
- TypeScript strict mode 通过

### Phase 2: 性能优化（1 周）

#### 2.1 设备自适应降级

**问题**：低端设备运行高粒子数量主题会卡顿。

**方案**：

```typescript
// src/utils/performanceDetector.ts
export type PerformanceLevel = 'high' | 'medium' | 'low';

export function detectPerformance(): PerformanceLevel {
  const memory = (performance as any).memory;
  const cores = navigator.hardwareConcurrency || 2;
  
  // 高性能：8+ 核心 或 4GB+ 内存
  if (cores >= 8 || (memory && memory.jsHeapSizeLimit > 4e9)) {
    return 'high';
  }
  
  // 中性能：4+ 核心
  if (cores >= 4) {
    return 'medium';
  }
  
  return 'low';
}

export const PERFORMANCE_PRESETS = {
  high: { particleMultiplier: 1.0, fpsLimit: 120 },
  medium: { particleMultiplier: 0.6, fpsLimit: 60 },
  low: { particleMultiplier: 0.3, fpsLimit: 30 },
};
```

**API 设计**：

```tsx
<ParticlesBackground 
  theme="starline" 
  performance="auto" // 'auto' | 'high' | 'medium' | 'low'
/>
```

**验收标准**：
- 低端设备自动降低粒子数量
- 提供手动性能档位选择
- FPS 低于 30 时自动降级

#### 2.2 FPS 监控与自动调整

**方案**：

```typescript
// src/hooks/useFPSMonitor.ts
export function useFPSMonitor(onLowFPS: () => void) {
  useEffect(() => {
    let frameCount = 0;
    let lastTime = performance.now();
    
    const checkFPS = () => {
      frameCount++;
      const now = performance.now();
      
      if (now - lastTime >= 1000) {
        const fps = frameCount;
        frameCount = 0;
        lastTime = now;
        
        if (fps < 30) {
          onLowFPS();
        }
      }
      
      requestAnimationFrame(checkFPS);
    };
    
    const rafId = requestAnimationFrame(checkFPS);
    return () => cancelAnimationFrame(rafId);
  }, [onLowFPS]);
}
```

**验收标准**：
- 实时监控 FPS
- FPS < 30 持续 3 秒触发降级
- 提供性能统计 API

#### 2.4 内存管理与资源清理

**问题**：组件卸载时未清理 WebGL 上下文和粒子实例，长时间使用或频繁切换主题会导致内存泄漏。

**方案**：

```typescript
// src/hooks/useParticleCleanup.ts
import { RefObject, useEffect } from 'react';

export function useParticleCleanup(containerRef: RefObject<HTMLElement>) {
  useEffect(() => {
    return () => {
      // 清理 WebGL 上下文，释放 GPU 资源
      const canvas = containerRef.current?.querySelector('canvas');
      const gl = canvas?.getContext('webgl') || canvas?.getContext('webgl2');
      if (gl) {
        gl.getExtension('WEBGL_lose_context')?.loseContext();
      }

      // 清理 Three.js 渲染器
      // renderer.dispose(); renderer.forceContextLoss();

      // 清理 tsparticles 实例
      // container.destroy();
    };
  }, []);
}
```

**验收标准**：
- 组件卸载时释放所有 WebGL 上下文
- Three.js 渲染器、几何体、材质正确 dispose
- tsparticles 容器正确销毁
- 频繁切换主题 50 次后内存无明显增长

#### 2.6 安全性

**问题**：自定义粒子图片等用户输入缺少校验，存在 XSS 风险。

**方案**：

```typescript
// src/utils/sanitize.ts
export function validateImageUrl(url: string): boolean {
  try {
    const parsed = new URL(url);
    return ['http:', 'https:', 'data:'].includes(parsed.protocol);
  } catch {
    return false;
  }
}

export function sanitizeCustomOptions(options: Record<string, any>): Record<string, any> {
  // 过滤危险属性，校验 URL 格式
  if (options?.particles?.shape?.image?.src) {
    if (!validateImageUrl(options.particles.shape.image.src)) {
      console.warn('[react-particle-backgrounds] 无效的图片 URL，已忽略');
      delete options.particles.shape.image;
    }
  }
  return options;
}
```

**验收标准**：
- 所有用户输入的 URL 经过校验
- 阻止 `javascript:` 等危险协议
- CSP 友好，不使用 `eval` 或内联脚本

#### 3.1 主题切换过渡动画

**问题**：主题切换瞬间完成，体验生硬。

**方案**：

```tsx
// src/components/ParticlesBackground.tsx
const [transitioning, setTransitioning] = useState(false);
const [prevTheme, setPrevTheme] = useState<string | null>(null);

useEffect(() => {
  if (prevTheme && prevTheme !== themeId) {
    setTransitioning(true);
    setTimeout(() => {
      setTransitioning(false);
      setPrevTheme(themeId);
    }, 600);
  } else {
    setPrevTheme(themeId);
  }
}, [themeId, prevTheme]);

return (
  <>
    {prevTheme && transitioning && (
      <div style={{ opacity: 1 - progress }}>
        {/* 旧主题 */}
      </div>
    )}
    <div style={{ opacity: transitioning ? progress : 1 }}>
      {/* 新主题 */}
    </div>
  </>
);
```

**验收标准**：
- 主题切换 600ms 淡入淡出

#### 8.4 开发者调试面板

**问题**：开发过程中难以直观观察粒子性能数据（FPS、粒子数、内存占用）。

**方案**：

```tsx
// src/components/ParticleDebugPanel.tsx
interface DebugPanelProps {
  fps: number;
  particleCount: number;
  memoryUsage?: number;
  performanceLevel: PerformanceLevel;
}

export function ParticleDebugPanel({ fps, particleCount, memoryUsage, performanceLevel }: DebugPanelProps) {
  if (process.env.NODE_ENV !== 'development') return null;

  return (
    <div style={{
      position: 'fixed', bottom: 8, right: 8,
      background: 'rgba(0,0,0,0.8)', color: '#0f0',
      padding: '8px 12px', borderRadius: 6, fontSize: 12,
      fontFamily: 'monospace', zIndex: 9999,
    }}>
      <div>FPS: {fps}</div>
      <div>Particles: {particleCount}</div>
      {memoryUsage && <div>Memory: {(memoryUsage / 1024 / 1024).toFixed(1)}MB</div>}
      <div>Level: {performanceLevel}</div>
    </div>
  );
}
```

**API 设计**：

```tsx
<ParticlesBackground 
  theme="starline"
  debug={true}  // 仅开发环境生效
/>
```

**验收标准**：
- 开发环境显示实时性能数据
- 生产环境自动移除（tree-shaking）
- 不影响粒子渲染性能

#### 10.1 Web Vitals 集成

**问题**：缺少量化数据衡量粒子背景对页面性能的实际影响。

**方案**：

```typescript
// src/utils/webVitals.ts
import { getCLS, getFID, getFCP, getLCP, getTTFB } from 'web-vitals';

type MetricHandler = (metric: { name: string; value: number }) => void;

export function reportWebVitals(onPerfEntry?: MetricHandler) {
  if (onPerfEntry) {
    getCLS(onPerfEntry);
    getFID(onPerfEntry);
    getFCP(onPerfEntry);
    getLCP(onPerfEntry);
    getTTFB(onPerfEntry);
  }
}
```

**验收标准**：
- 提供可选的 Web Vitals 集成
- 不增加核心包体积（独立入口）
- 提供性能基准数据文档

**方案**：

```tsx
<ParticlesBackground
```
